01

역량과 README 연결

NCS 기반 지식·기술·태도를 자기점검하고, GitHub README에서 프로젝트 경험을 정리해요. README와 이력서는 건너뛰어도 연습할 수 있어요.

02

이력서 PDF 분석

선택적으로 이력서를 제출해 기술·경험을 정리해요. 추출한 내용을 직접 확인·수정하고, 추천에 사용할 정보를 확정해요.

03

맞춤 공고 추천과 검색

선택한 역량과 확인한 경험을 바탕으로 공고를 추천받고 검색해요. 공고 원문을 확인·분석한 뒤 연습에 연결할 요구사항을 선택해요.

04

내 질문으로 면접 연습

기본 질문 외에도 연습하고 싶은 면접 질문을 직접 입력할 수 있어요. 선택한 질문으로 답변하고 코칭을 받아요.

05

전사문 확인과 표준어 변환

인식한 답변을 직접 수정하거나 사투리·말투를 다듬을 수 있어요. STT 원문, 변경 내역, 확인이 필요한 표현을 살펴보고 확정해요.

06

자유채팅과 경험 추가

준비 과정과 1차 코칭 후 궁금한 점을 물어보고 경험·경력을 추가해요. 저장 전 내용을 확인하고, 동의한 정보를 연습 맥락에 반영해요.

07

이력서 초안부터 PDF까지

재답변 비교 후 확인한 경험을 프로젝트·경력 중심 초안으로 정리해요. 자료 가져오기에 동의하고 내용을 보완·다듬은 뒤 이력서 PDF로 다운로드해요.

08

연습 기록 다시 보기

지난 연습의 결과와 연결된 채팅 내역을 확인해요. 기록은 생성 후 최대 24시간 보관되며, 개별 기록이나 전체 기록을 직접 삭제할 수 있어요.

이력서·README는 참고 자료이며 코칭의 답변 근거를 대신하지 않아요. 이력서 문장 다듬기도 사용자 확인을 기준으로 하며, 최종 내용은 다운로드 전에 검토해 주세요.

06 · FAQ

궁금한 점이
있으신가요?

연습을 시작하기 전에 알아두면 좋은 내용을 모았어요.

?
GitHub README 제출은 필수인가요?+

아니요. README와 이력서 PDF 모두 선택 사항이에요. 자료 없이도 선택한 역량과 채팅으로 확인한 경험을 바탕으로 진행할 수 있어요.

완성한 이력서를 다운로드할 수 있나요?+

재답변 비교 후 이력서 초안을 작성할 수 있어요. 프로젝트·경력 중심 형식을 선택하고 내용을 보완·다듬은 뒤, 재구성한 이력서를 PDF로 다운로드할 수 있어요.

마이크가 없어도 연습할 수 있나요?+

마이크 녹음 대신 WAV 파일을 제출할 수 있어요.

답변이 잘못 전사되면 어떻게 하나요?+

AI 분석 전에 전사문을 직접 확인하고 수정·확정할 수 있어요. 표준어 변환을 선택한 경우 STT 원문과 변경 내역, 확인이 필요한 표현도 함께 검토할 수 있어요.

연습 기록은 얼마나 보관되나요?+

연습 기록은 생성 후 최대 24시간 보관돼요. 연습 기록 화면에서 결과와 채팅 내역을 확인하고, 개별·전체 기록을 직접 삭제할 수 있어요. 이력서 PDF 다운로드는 별도의 이력서 작성 기능입니다.
