# 연습 종료 로딩 카드

## Why
종료 요약 대기가 다른 분석 로딩과 달리 작은 점 안내로 남아 있음.
## Goal
종료 요청 대기 시 제공된 캐릭터와 기존 큰 로딩 카드 1개 표시. 다른 대화 대기와 API 동작은 범위 밖.
## What
연습 마치기 및 종료 재시도 중 카드 표시, 응답/오류 시 제거.
## How
CoachLoadingCard 재사용. 제공 PNG 사용. 종료 API 세부 이벤트가 없으므로 종료 요약 대기 사실만 표시.
## AC
Given 활성 면접 대화, When 연습 마치기 요청이 대기 중, Then 새 캐릭터 카드와 애니메이션 진행 표시가 보이고 기존 아래 이동이 유지된다. 성공/오류 후 카드는 사라진다.
