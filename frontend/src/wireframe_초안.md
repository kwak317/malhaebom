# 말해봄 프론트엔드 와이어프레임 초안

> **상태: historical snapshot.** 초기 프론트엔드 초안을 보존한 문서이며 현재 MVP 범위나 구현 계약의 canonical이 아니다. 현재 제품 범위는 `docs/CONSTRAINTS.md`, 연습 설정·직접 입력 질문 계약은 `docs/specs/practice-setup-and-question-tts.md`를 따른다.
> 아래의 “현재 범위”, “제외/보류” 표현은 작성 당시 기준이며 현재 상태로 해석하지 않는다.
> 작성 방식: 화면 구조, UI 요소, 버튼, 상태, 화면 이동을 정의한다. 디자인 색상과 세부 스타일은 이 문서에서 결정하지 않는다.
> 현재 범위: 첫 화면 → 질문 선택 → 마이크 확인 → 녹음 → 녹음 완료 → 분석 → 분석 결과 → TTS 피드백 예시 → 재녹음 → 1차/2차 비교
> 제외/보류: 직접 작성 질문, 답변 구성 분석, 음량/억양 분석, 강한 자동 개선 판정은 현재 MVP 와이어프레임에 포함하지 않는다.

## 0. 첫 화면

### 화면 목적

서비스의 메인 진입 화면이다. 사용자가 서비스 이용 흐름을 짧게 이해하고, `연습하기`를 통해 새 연습을 시작하거나 `연습 기록`으로 현재 탭 세션의 결과를 확인할 수 있게 한다. 분석 수치와 복잡한 기능은 이 화면에 표시하지 않는다.

### 필요한 UI 요소

- 상단 헤더
  - 왼쪽: 서비스명 `말해봄`
  - 오른쪽: `연습 기록`, `로그인 / 회원가입`
- 본문 카드 2개
  - `이용 안내`: 서비스와 연습 흐름의 간단한 설명
  - `연습하기`: 면접 연습 시작 카드 및 주요 진입 버튼

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────────────┐
│ 말해봄              연습 기록  로그인/회원가입 │
├────────────────────────────────────────────┤
│ ┌──────────────────┐ ┌──────────────────┐ │
│ │ 이용 안내        │ │ 연습하기         │ │
│ │ 질문 선택        │ │ 면접 연습을      │ │
│ │ → 녹음 → 분석    │ │ 시작해 보세요.   │ │
│ │ → 다시 연습      │ │ [연습하기]       │ │
│ └──────────────────┘ └──────────────────┘ │
└────────────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 연습하기

- 동작: 새 연습 흐름을 시작한다.
- 다음 화면: `질문 선택 화면`

#### 연습 기록

- 동작: 현재 탭 세션에 남아 있는 완료 연습을 확인한다.
- 다음 화면: `연습 기록 화면`

#### 로그인 / 회원가입

- 동작: 로그인 또는 회원가입 진입점만 제공한다.
- 참고: 로그인 후 영구 저장 정책이나 DB 구조는 이번 범위에서 정의하지 않는다.

### 필요한 상태

```text
PracticeStep
- landing
```

### 상태별 화면 처리

- 기본: 두 카드와 헤더 메뉴를 표시한다.
- 현재 세션에 기록이 없더라도 `연습 기록` 메뉴는 표시하며, 선택 시 빈 기록 안내를 보여준다.

### Figma용 간단 텍스트 와이어프레임

```text
화면: 첫 화면

┌────────────────────────────────────────────┐
│ 말해봄              연습 기록  로그인/회원가입 │
├────────────────────────────────────────────┤
│ ┌──────────────────┐ ┌──────────────────┐ │
│ │ 이용 안내        │ │ 연습하기         │ │
│ │ 서비스 소개      │ │ 면접 연습 시작   │ │
│ │ 연습 흐름 안내   │ │                  │ │
│ │                  │ │ [연습하기]       │ │
│ └──────────────────┘ └──────────────────┘ │
└────────────────────────────────────────────┘
```

## 1. 질문 선택 화면

### 화면 목적

사용자가 기본 면접 질문 하나를 선택하고, 선택한 질문을 확인한 뒤 녹음 준비 단계로 이동한다. 직접 작성 질문은 제공하지 않는다.

### 필요한 UI 요소

- 화면 제목: `질문`
- 기본 질문 목록
  - `1분 자기소개를 해주세요.`
  - `이 직무에 지원한 이유는 무엇인가요?`
  - `팀원과 갈등을 해결한 경험이 있나요?`
- 현재 선택한 질문 표시 영역
- `녹음 시작하기` 또는 다음 단계 이동 버튼
- 첫 화면으로 돌아가기 버튼 또는 링크

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────┐
│ ← 첫 화면              질문         │
├────────────────────────────────────┤
│ [ ] 1분 자기소개를 해주세요.         │
│ [ ] 이 직무에 지원한 이유는 무엇인가요?│
│ [ ] 팀원과 갈등을 해결한 경험이 있나요?│
├────────────────────────────────────┤
│ 현재 선택한 질문                     │
│ 선택된 질문이 없습니다.              │
├────────────────────────────────────┤
│ [녹음 시작하기] 비활성               │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 질문 카드 선택

- 동작: 선택한 질문을 현재 세션의 `activeQuestionId`로 저장하고, 현재 선택한 질문 영역에 표시한다.
- 다음 상태: `presetQuestionSelected`

#### 녹음 시작하기

- 표시/활성 조건: 기본 질문이 선택되어 있음
- 동작: 마이크 상태 확인 단계로 이동한다.
- 다음 화면: `마이크 상태 확인`

### 필요한 상태

```text
PracticeStep
- questionSelect
```

```text
QuestionSelectionState
- noQuestionSelected
- presetQuestionSelected
```

### 상태별 화면 처리

#### 질문 선택 전

```text
현재 선택한 질문:
선택된 질문이 없습니다.

버튼:
[녹음 시작하기] 비활성 또는 숨김
```

#### 질문 선택 후

```text

"1분 자기소개를 해주세요."

버튼:
[녹음 시작하기] 활성
```

```text
│ ┌────────────────────────────────────────┐ │
│ │ 팀원과 갈등을 해결한 경험이 있나요?     │ │
```

## 2. 마이크 상태 확인

### 화면 목적

선택한 질문과 답변 시간 조건을 확인하고, 녹음 시작 전 브라우저 마이크 권한 상태를 명확히 안내한다. 권한이 허용되기 전에는 녹음을 시작할 수 없다.

### 필요한 UI 요소

- `질문 다시 선택` 이동
- 선택한 질문
- 답변 시간 안내: 최소 5초, 최대 60초
- 마이크 사용 안내
- `마이크 권한 확인` 버튼
- 권한 확인 중 상태
- 마이크 준비 완료 상태
- 권한 허용 후 `녹음 시작하기` 버튼

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────┐
│ ← 질문 다시 선택                    │
├────────────────────────────────────┤
│ 선택한 질문                         │
│ "1분 자기소개를 해주세요."          │
├────────────────────────────────────┤
│ 답변 안내: 최소 5초 ~ 최대 60초      │
├────────────────────────────────────┤
│ 답변을 녹음하려면 마이크 사용 권한이 │
│ 필요합니다.                         │
│ [마이크 권한 확인]                  │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 질문 다시 선택

- 동작: 현재 질문 선택 화면으로 돌아간다.
- 다음 화면: `질문 선택 화면`

#### 마이크 권한 확인

- 동작: 브라우저 마이크 권한을 요청한다.
- 다음 상태: `pending` → `granted` 또는 `denied`

#### 녹음 시작하기

- 표시 조건: `MicState`가 `granted`
- 동작: 첫 번째 Attempt를 준비하고 녹음을 시작한다.
- 다음 화면: `1차 녹음 중 화면`

### 필요한 상태

```text
PracticeStep
- micCheck
```

```text
MicState
- unknown
- pending
- granted
- denied
```

### 상태별 화면 처리

#### 권한 확인 전

```text
안내: 답변을 녹음하려면 마이크 사용 권한이 필요합니다.
버튼: [마이크 권한 확인]
녹음 시작하기: 표시하지 않음
```

#### 권한 요청 중

```text
안내: 마이크 권한을 확인하는 중입니다.
버튼: [확인 중...] 비활성
녹음 시작하기: 표시하지 않음
```

#### 권한 허용

```text
안내: ✓ 마이크 준비 완료
버튼: [녹음 시작하기]
```

#### 권한 거부

```text
안내: 마이크 권한이 필요해요.
브라우저 설정에서 마이크 권한을 허용한 뒤 다시 시도해 주세요.
버튼: [다시 확인]
녹음 시작하기: 표시하지 않음
```

### Figma용 간단 텍스트 와이어프레임

```text
화면: 마이크 상태 확인 / 마이크 준비 완료

┌────────────────────────────────────────────┐
│ ← 질문 다시 선택                            │
```

## 3. 녹음 중 화면

### 화면 목적

선택한 질문에 답변을 녹음하는 화면이다. 사용자가 녹음 상태와 시간을 인지하고, 일시정지 또는 종료할 수 있게 한다. 이 단계에서는 분석 정보와 피드백을 표시하지 않는다.

### 필요한 UI 요소

- 현재 질문
- 음성 파형 또는 녹음 중 시각 요소
- 현재 녹음 시간
- 최대 60초 표시
- `그만하기`, `일시정지` 버튼
- 일시정지 상태의 `계속 녹음하기` 버튼

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────┐
│ 질문                               │
│ "1분 자기소개를 해주세요."          │
├────────────────────────────────────┤
│                                    │
│       ~~~~ 음성 파형 ~~~~           │
│                                    │
│            00:32 / 01:00           │
├────────────────────────────────────┤
│ [그만하기]          [일시정지]      │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 그만하기

- 동작: 현재 녹음을 종료하고 음성 데이터를 완료 상태로 전환한다.
- 다음 화면: `녹음 완료 화면`

#### 일시정지 / 계속 녹음하기

- 동작: 녹음 상태를 `recording`과 `paused` 사이에서 전환한다.
- 다음 화면: 현재 화면 유지

#### 60초 자동 종료

- 동작: 녹음 시간이 최대 60초에 도달하면 자동으로 녹음을 종료한다.
- 다음 화면: `녹음 완료 화면`

### 필요한 상태

```text
PracticeStep
- recording
- secondRecording
```

```text
RecordingState
- idle
- recording
- paused
- completed
```

### 상태별 화면 처리

- `recording`: 파형 또는 녹음 시각 요소를 활성 상태로 표시하고, `일시정지`를 제공한다.
- `paused`: 타이머 진행을 멈추고 `계속 녹음하기`를 제공한다.
- 60초 도달: 사용자 입력 없이 `completed`로 전환한 뒤 녹음 완료 화면으로 이동한다.

### Figma용 간단 텍스트 와이어프레임

```text
화면: 1차 녹음 중

┌────────────────────────────────────────────┐
│ 질문: "1분 자기소개를 해주세요."             │
├────────────────────────────────────────────┤
│                                            │
│             ~~~~ 음성 파형 ~~~~             │
│                                            │
│                00:32 / 01:00                │
├────────────────────────────────────────────┤
│ [그만하기]                  [일시정지]      │
└────────────────────────────────────────────┘
```

## 4. 녹음 완료 화면

### 화면 목적

녹음 직후 분석을 시작하기 전에 사용자가 자신의 녹음과 총 시간을 확인하고, 다시 녹음하거나 분석을 선택하게 한다.

### 필요한 UI 요소

- 현재 질문
- 녹음된 음성 파형
- 총 녹음 시간
- 녹음 다시 듣기 음성 플레이어
- 주요 CTA: `분석하기`
- 보조 액션: `다시 녹음`

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────┐
│ 질문: "1분 자기소개를 해주세요."     │
├────────────────────────────────────┤
│       ~~~~ 녹음된 음성 파형 ~~~~      │
│ 총 녹음 시간 00:42                  │
│ [▶ 녹음 다시 듣기]                   │
├────────────────────────────────────┤
│ [다시 녹음]          [분석하기]      │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 분석하기

- 동작: 현재 Attempt의 음성을 분석 요청 상태로 전환한다.
- 다음 화면: `분석 중 화면`

#### 다시 녹음

- 동작: 현재 Attempt의 녹음을 새로 시작한다. 질문은 유지한다.
- 다음 화면: 현재 Attempt의 `녹음 중 화면`

### 필요한 상태

```text
RecordingState
- completed
```

```text
AnalysisState
- idle
```

### 상태별 화면 처리

- 녹음 데이터가 완성된 경우에만 `분석하기`를 활성화한다.
- 재녹음 후에는 이전 미분석 녹음 대신 새 녹음을 현재 Attempt의 대상으로 사용한다.

### Figma용 간단 텍스트 와이어프레임

```text
화면: 녹음 완료

┌────────────────────────────────────────────┐
│ 질문: "1분 자기소개를 해주세요."             │
├────────────────────────────────────────────┤
│           ~~~~ 녹음된 음성 파형 ~~~~         │
│ 총 녹음 시간 00:42                           │
│ [▶ 녹음 다시 듣기]                           │
├────────────────────────────────────────────┤
│ [다시 녹음]                    [분석하기]   │
└────────────────────────────────────────────┘
```

## 5. 분석 중 화면

### 화면 목적

현재 Attempt의 답변을 분석하고 있음을 간결하게 알린다. 분석 결과와 세부 지표는 완료 전까지 표시하지 않는다.

### 필요한 UI 요소

- 로딩 아이콘
- 안내 문구
  - `답변을 분석하고 있어요.` 또는
  - `말하기 습관을 확인하고 있어요.`

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────┐
│                                    │
│              ◌ 로딩 아이콘          │
│                                    │
│     답변을 분석하고 있어요.          │
│                                    │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

- 분석 완료: 현재 Attempt에 따라 `1차 분석 결과` 또는 `2차 분석 결과`로 자동 이동한다.
- 분석 오류: 현재 화면에서 오류 안내와 재시도 또는 녹음 완료 화면으로 돌아가는 선택지를 제공한다.

### 필요한 상태

```text
AnalysisState
- analyzing
- completed
- error
```

### 상태별 화면 처리

- `analyzing`: 로딩과 안내 문구만 표시한다.
- `completed`: 분석 결과 화면으로 자동 이동한다.
- `error`: 결과를 임의로 표시하지 않고, `다시 분석하기`와 `녹음 확인으로`를 제공한다.

### Figma용 간단 텍스트 와이어프레임

```text
화면: 분석 중

┌────────────────────────────────────────────┐
│                                            │
│                  ◌                         │
│                                            │
│        말하기 습관을 확인하고 있어요.       │
│                                            │
└────────────────────────────────────────────┘
```

## 6. 1차 분석 결과 화면

### 화면 목적

첫 번째 답변의 세 가지 핵심 분석 항목과 최대 두 개의 핵심 피드백을 보여준다. 피드백을 반영한 예시 음성을 듣고 같은 질문으로 재녹음할 수 있게 한다.

### 필요한 UI 요소

- 상단 제목: `분석 결과`
- 선택한 질문
- 분석 결과
  - 말하기 속도: CPM
  - 긴 침묵: 횟수
  - 반복 표현: 횟수
- 피드백: 최대 2개
- TTS 예시 음성 플레이어
  - `피드백 반영 음성 듣기 ▶`
- `재녹음하기` 버튼

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────┐
│ 분석 결과                           │
│ "1분 자기소개를 해주세요."          │
├────────────────────────────────────┤
│ 분석 결과                           │
│ 말하기 속도      270 CPM             │
│ 긴 침묵          2회                 │
│ 반복 표현        3회                 │
├────────────────────────────────────┤
│ 피드백                              │
│ • 조금 빠르게 말했어요.              │
│ • 3초 이상의 긴 침묵이 2번 있었어요. │
├────────────────────────────────────┤
│ [피드백 반영 음성 듣기 ▶]            │
│                                    │
│ [재녹음하기]                        │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 피드백 반영 음성 듣기

- 동작: 현재 답변을 크게 바꾸지 않고, 안정적인 속도·긴 침묵 감소·반복 표현 감소를 반영한 TTS 예시를 재생 또는 일시정지한다.
- 다음 화면: 현재 화면 유지

#### 재녹음하기

- 동작: 동일한 `activeQuestionId`로 `second` Attempt를 생성한다.
- 다음 화면: `2차 녹음 중 화면`

### 필요한 상태

```text
PracticeStep
- firstResult
```

```text
Attempt
- first
- second
```

```text
TtsPlayerState
- idle
- playing
- paused
- unavailable
```

### 상태별 화면 처리

- 피드백: 핵심 피드백은 최대 2개만 표시한다.
- TTS 재생 중: 재생 진행 상태와 `일시정지` 제어를 제공한다.
- TTS를 사용할 수 없는 경우: 분석 지표와 재녹음 흐름은 유지하고, 음성 예시를 사용할 수 없다는 안내만 표시한다.

### Figma용 간단 텍스트 와이어프레임

```text
화면: 1차 분석 결과

┌────────────────────────────────────────────┐
│ 분석 결과                                   │
│ "1분 자기소개를 해주세요."                  │
├────────────────────────────────────────────┤
│ 말하기 속도                    270 CPM      │
│ 긴 침묵                        2회          │
│ 반복 표현                      3회          │
├────────────────────────────────────────────┤
│ 피드백                                      │
│ • 조금 빠르게 말했어요.                     │
│ • 3초 이상의 긴 침묵이 2번 있었어요.        │
├────────────────────────────────────────────┤
│ [피드백 반영 음성 듣기 ▶]                   │
│                                            │
│ [재녹음하기]                                 │
└────────────────────────────────────────────┘
```

## 7. 피드백 반영 예시 음성

### 화면 목적

1차 분석 결과 안에서 제공되는 TTS 예시 음성 영역이다. 답변의 내용 자체를 평가하거나 바꾸지 않고, 피드백을 반영한 전달 방식을 청취하게 한다.

### 필요한 UI 요소

- 영역 제목: `피드백 반영 음성`
- 설명: `피드백을 반영했을 때의 전달 방식 예시예요.`
- 오디오 플레이어
  - 재생 / 일시정지
  - 재생 시간 또는 진행 표시
  - `피드백 반영 음성 듣기 ▶`

### 주요 버튼과 다음 화면으로의 이동

- 재생/일시정지: TTS만 제어하며 화면은 이동하지 않는다.
- 재녹음하기: 1차 분석 결과 화면의 CTA를 통해 `2차 녹음 중`으로 이동한다.

### 필요한 상태

```text
TtsPlayerState
- idle
- playing
- paused
- unavailable
```

### 상태별 화면 처리

- `idle`: 재생 버튼을 표시한다.
- `playing`: 재생 진행과 일시정지 버튼을 표시한다.
- `paused`: 멈춘 시점에서 재생 재개 버튼을 표시한다.
- `unavailable`: TTS 제공 불가 안내를 표시하되 재녹음 버튼은 유지한다.

### Figma용 간단 텍스트 와이어프레임

```text
영역: 피드백 반영 예시 음성

┌────────────────────────────────────────────┐
│ 피드백 반영 음성                            │
│ 피드백을 반영했을 때의 전달 방식 예시예요. │
│ [▶ 피드백 반영 음성 듣기]                   │
│ ━━━━━━━○──────── 00:12 / 00:35             │
└────────────────────────────────────────────┘
```

## 8. 재녹음하기

### 화면 목적

1차 분석 결과 후 같은 질문으로 두 번째 답변을 녹음하게 한다. 질문을 다시 고르는 단계는 거치지 않는다.

### 필요한 UI 요소

- 1차 분석 결과 하단의 `재녹음하기` CTA
- 동일 질문 유지 안내
- 2차 녹음 중 화면의 질문·타이머·녹음 제어

### 주요 버튼과 다음 화면으로의 이동

#### 재녹음하기

- 동작: `second` Attempt를 생성하고 기존 `activeQuestionId`를 그대로 사용한다.
- 다음 화면: `2차 녹음 중 화면`

### 필요한 상태

```text
Attempt
- first
- second
```

```text
PracticeStep
- secondRecording
```

### 상태별 화면 처리

- 2차 Attempt가 시작되기 전까지 1차 결과는 유지한다.
- 질문 변경 기능은 이 흐름에 표시하지 않는다.
- 2차 녹음 완료 후에는 1차와 동일하게 `녹음 완료` → `분석 중` → `2차 분석 결과` 흐름을 따른다.

### Figma용 간단 텍스트 와이어프레임

```text
흐름: 재녹음 시작

[1차 분석 결과]
       │
       └─ [재녹음하기]
              │
              ▼
┌────────────────────────────────────────────┐
│ 2차 답변 녹음                               │
│ 질문: "1분 자기소개를 해주세요."             │
│ [그만하기]                  [일시정지]      │
└────────────────────────────────────────────┘
```

- 상단 제목: `분석 결과`

- 말하기 속도, 긴 침묵, 반복 표현
- 핵심 피드백 최대 2개

```text
│ • 핵심 피드백 2                     │
├────────────────────────────────────┤
│ [1차 · 2차 결과 비교하기]           │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 1차 · 2차 결과 비교하기

- 다음 화면: `1차 / 2차 결과 비교 화면`

### 필요한 상태

```text
PracticeStep
```

```text
AnalysisState
```

- 1차 화면과 동일하게 피드백은 최대 2개만 표시한다.

## 10. 1차 / 2차 결과 비교 화면

### 화면 목적

같은 질문의 1차와 2차 분석 수치를 한 화면에서 비교한다. 개선 여부를 강하게 자동 판정하지 않고, 수치 변화 자체를 중심으로 보여준다.

### 필요한 UI 요소

- 상단 제목: `1차 · 2차 결과 비교`
- 좌우 결과 카드 2개
  - `1차 분석 결과`
  - `2차 분석 결과`
- 카드별 동일 지표
  - 말하기 속도
  - 긴 침묵
  - 반복 표현
- `더 좋아진 점 확인하기` 펼침 버튼
- 수치 변화 영역
- `첫 화면으로` 버튼

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────────────┐
│ 1차 · 2차 결과 비교                         │
├──────────────────┬─────────────────────────┤
│ 1차 분석 결과    │ 2차 분석 결과            │
│ 말하기 속도      │ 말하기 속도              │
│ 310 CPM          │ 270 CPM                  │
│ 긴 침묵 3회      │ 긴 침묵 1회              │
│ 반복 표현 4회    │ 반복 표현 2회            │
├────────────────────────────────────────────┤
│ [더 좋아진 점 확인하기]                     │
│ (선택 시 수치 변화 영역 펼침)               │
├────────────────────────────────────────────┤
│ [첫 화면으로]                               │
└────────────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 더 좋아진 점 확인하기

- 동작: 수치 변화 영역을 펼치거나 접는다.
- 다음 화면: 현재 화면 유지
- 안내: 필요한 경우 `적정 범위에 가까워졌어요` 같은 가벼운 문구를 사용할 수 있으나, 자동으로 좋음/나쁨을 강하게 판정하지 않는다.

#### 첫 화면으로

- 동작: 현재 연습 흐름을 마치고 메인 진입 화면으로 이동한다.
- 다음 화면: `첫 화면`

### 필요한 상태

```text
PracticeStep
- compare
```

```text
ComparisonDetailState
- collapsed
- expanded
```

### 상태별 화면 처리

#### 기본 비교

```text
1차와 2차 카드에 각 지표의 현재 수치를 표시한다.
수치 변화 영역은 접힌 상태다.
```

#### 수치 변화 펼침

```text
말하기 속도: 310 → 270 CPM
긴 침묵: 3회 → 1회
반복 표현: 4회 → 2회
```

### Figma용 간단 텍스트 와이어프레임

```text

┌────────────────────────────────────────────┐
│ 1차 · 2차 결과 비교                         │
├──────────────────┬─────────────────────────┤
│ 1차 분석 결과    │ 2차 분석 결과            │
│ 말하기 속도      │ 말하기 속도              │
│ 310 CPM          │ 270 CPM                  │
│ 긴 침묵 3회      │ 긴 침묵 1회              │
│ 반복 표현 4회    │ 반복 표현 2회            │
├────────────────────────────────────────────┤
│ [더 좋아진 점 확인하기]                     │
├────────────────────────────────────────────┤
│ 말하기 속도: 310 → 270 CPM                  │
│ 긴 침묵: 3회 → 1회                          │
│ 반복 표현: 4회 → 2회                        │
```

## 11. 연습 기록

### 화면 목적

첫 화면 헤더의 `연습 기록`에서 현재 탭 세션 동안 완료한 질문별 연습 결과를 확인한다. 상세 디자인보다 목록과 결과 접근 흐름을 정의한다.

### 필요한 UI 요소

- 화면 제목: `연습 기록`
- 기록 목록 항목
  - 연습한 질문
  - 연습 날짜/시간
  - 1차 분석 결과 요약
  - 2차 분석 결과 존재 여부
  - 비교 가능 상태
- 빈 기록 안내
- 첫 화면으로 돌아가기

### 위에서 아래로 보이는 화면 배치

```text
┌────────────────────────────────────┐
│ ← 첫 화면          연습 기록        │
├────────────────────────────────────┤
│ 1분 자기소개를 해주세요.             │
│ 2026.08.18 14:30                    │
│ 1차 결과: 270 CPM / 긴 침묵 2회      │
│ 2차 결과 있음  [비교 보기]           │
├────────────────────────────────────┤
│ 이 직무에 지원한 이유는 무엇인가요?  │
│ 2026.08.18 13:10                    │
│ 1차 결과: 250 CPM / 긴 침묵 1회      │
│ 2차 결과 없음                        │
└────────────────────────────────────┘
```

### 주요 버튼과 다음 화면으로의 이동

#### 기록 항목 또는 비교 보기

- 동작: 해당 질문의 저장된 현재 탭 세션 결과를 확인한다.
- 2차 결과가 있는 경우 다음 화면: `1차 / 2차 결과 비교 화면`
- 2차 결과가 없는 경우: 1차 분석 결과 요약을 표시한다.

#### 첫 화면으로

- 동작: 첫 화면으로 돌아간다.
- 다음 화면: `첫 화면`

### 필요한 상태

```text
SessionResultState
- empty
- hasResults
```

```text
StoragePolicy
- sessionStorage: 질문, 결과 요약 등 현재 탭 세션 데이터 유지
- memory/object URL 또는 서버 임시 ID: 원본 음성 및 TTS 음성 관리
- localStorage: 사용하지 않음
```

### 상태별 화면 처리

- 기록 없음: `아직 연습 기록이 없어요.`와 `연습하기` 버튼을 표시한다.
- 2차 결과 없음: 비교 버튼을 제공하지 않는다.
- 새로고침: sessionStorage 범위의 기록 정보는 유지한다.
- 탭 종료: 세션 기록은 삭제된다. 새로운 영구 저장 또는 DB 저장 구조는 추가하지 않는다.
