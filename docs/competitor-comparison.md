# 경쟁 서비스 대비 — 공고 요구·프로젝트 기술 근거 간극 진단

> 작성일: 2026-09-22
> 비교 대상: 사람인 AI 모의면접, RoundJump, GitHub Copilot, SkillBridge, GrillKit의 공개 안내·README. 공개 페이지에 없는 기능을 ‘미제공’이라고 단정하지 않으며, 이 문서는 제품 포지셔닝과 구현 범위를 위한 비교 기록이다.

## 비교 목적

말해봄은 일반적인 AI 모의면접, 공고 맞춤 질문, 답변 피드백, 꼬리질문 또는 GitHub 저장소 기반 질문이라는 기능 존재 여부로 경쟁하지 않는다. 신입 백엔드 준비생이 **선택한 공고의 요구사항과 이 프로젝트에서 확인되는 기술 근거 사이에 어떤 간극이 있는지** 확인하고, 그 간극을 과장 없이 답변으로 보완하게 하는 것을 차별 가치로 둔다.

## 공개 정보 기준의 사람인 기능

사람인의 AI 모의면접 공개 소개는 다음을 안내한다.

- 사람인 채용 공고 URL을 입력해 기업·직무에 맞춘 면접 연습을 제공한다.
- 답변 가이드, 실시간 행동 코칭, 답변별 맞춤 피드백을 제공한다.
- 답변을 바탕으로 이어지는 꼬리질문을 제공한다.

출처: [사람인 AI 모의면접](https://www.saramin.co.kr/zf_user/member/ai-interview), 2026-09-22 확인. 사람인의 공개 안내만으로 내부 구현, 전체 기능, 미제공 기능을 판단하지 않는다.

## GitHub를 읽는 에이전트·면접 도구 조사

### RoundJump — 가장 가까운 직접 비교 대상

[RoundJump](https://roundjump.com/)는 공개 GitHub/GitLab 저장소 또는 문서를 받아 아키텍처·결정·트레이드오프·기여도에 관한 프로젝트 면접을 연습시키며, 저장소 근거 기반 질문과 적응형 후속 질문을 공개적으로 안내한다. 프로젝트를 화면에서 탐색하고 변경·디버깅을 설명하는 연습도 제공한다.

따라서 **‘GitHub를 읽어 프로젝트 기반 꼬리질문을 낸다’는 기능은 말해봄의 차별점으로 주장하지 않는다.** 말해봄의 경계는 저장소 탐색 자체가 아니라, 선택 공고의 구체적 요구사항마다 프로젝트 근거·답변 근거·설명 간극을 추적하고 같은 기준으로 재답변을 비교하는 데 있다.

출처: [RoundJump 공개 안내](https://roundjump.com/), 2026-09-22 확인.

### GitHub Copilot — 범용 저장소 이해·개발 에이전트

[GitHub Copilot](https://docs.github.com/en/copilot/get-started/about-github-copilot)은 코드베이스 질문, 코드·PR 검토, 작업 계획·구현, repository research를 지원하는 개발 생산성 도구다. 저장소와 issue·PR·자동화를 개발 워크플로 안에서 다루며, 사용자는 변경을 검토·승인한다.

말해봄은 코드 변경·PR 생성을 하지 않고, 선택 공고와 면접 답변을 위한 제한된 근거 추출에만 저장소를 사용한다. 특히 저장소의 코드·이력은 기여 사실의 증거가 아니므로, 사용자가 설명 가능한 기여 범위를 확인해야만 면접 근거가 된다.

출처: [GitHub Copilot 공식 문서](https://docs.github.com/en/copilot/get-started/about-github-copilot), 2026-09-22 확인.

### SkillBridge — 이력서 기반 스킬 갭·학습 로드맵

[SkillBridge](https://github.com/prithvifr/SkillBridge)는 이력서와 채용 공고를 비교해 readiness score, 학습 로드맵, 음성 면접 연습을 제공한다고 공개 README에 설명한다.

말해봄은 점수·전체 학습 로드맵으로 개인의 취업 준비도를 판단하지 않는다. 저장소에서 확인 가능한 기술 근거와 현재 발화의 설명 간극을 공고 요구사항 1~2개에 한정해 보여 주며, `저장소 기준 미확인`을 경험 부재나 역량 부족으로 바꾸지 않는다.

출처: [SkillBridge 공개 README](https://github.com/prithvifr/SkillBridge), 2026-09-22 확인.

### GrillKit — 범용 기술면접 문제은행·점수화

[GrillKit](https://github.com/GrillKit/grillkit)은 Python·Kafka·시스템 설계 등 문제은행을 기반으로 이론/라이브 코딩 세션, 최대 2회의 후속 질문, 1~5점 점수와 결과 기록을 제공하는 오픈소스 기술면접 트레이너다.

말해봄은 범용 기술 문제 정답이나 답변 점수를 중심에 두지 않는다. 사용자가 실제로 선택한 프로젝트와 공고의 교차점에서, 역할·선택 이유·검증이 답변으로 증명됐는지를 다룬다.

출처: [GrillKit 공개 README](https://github.com/GrillKit/grillkit), 2026-09-22 확인.

## 한 문장 포지셔닝

**말해봄은 선택한 공고의 요구사항과 이 프로젝트에서 확인되는 기술 근거 사이의 간극을, 사용자가 확인한 기여 범위와 1·2차 답변의 실제 설명 보완으로 추적하는 신입 백엔드 면접 코치다.**

## 차별화 주장 시 지킬 표현

- 사용: “GitHub 저장소 기반 면접 연습 도구가 이미 있으므로, 말해봄은 저장소 읽기 자체가 아니라 선택 공고의 요구사항별 기술 근거·답변 근거·설명 간극을 고정 기준으로 비교하는 데 초점을 둔다.”
- 사용: “사람인의 공개 안내에서 확인한 공고 맞춤 면접·피드백과 달리, 말해봄은 사용자 확인 프로젝트 근거를 요구사항별 답변 보완과 재답변 비교에 연결하는 기능을 제안한다.”
- 사용하지 않음: “사람인에는 GitHub 연동이 없다.”
- 사용하지 않음: “GitHub 기반 면접 도구는 말해봄이 처음이다.”
- 사용하지 않음: “저장소의 기술 스택만으로 지원자의 역량·합격 가능성을 판단한다.”
- 사용하지 않음: “공고에 없는 최신·유행 기술도 부족 기술로 추천한다.”

## 검증이 필요한 가설

1. 사용자는 코드 전체 분석보다, 자신이 설명할 수 있다고 확인한 소수의 근거 카드 방식을 더 신뢰한다.
2. RoundJump 같은 프로젝트 기반 리허설과 비교해도, 공고 요구사항별 간극·근거 링크·재답변 변화가 분명한 추가 가치를 만든다.
3. `저장소 기준 미확인`이라는 중립적 표현이 경험 부재 단정 없이 다음 준비 행동을 유도한다.
4. 선택 이유·트레이드오프·검증에 초점을 둔 근거 연결형 질문이 일반 기술 퀴즈보다 답변 보완에 도움이 된다.

이 가설은 실제 사용자 테스트와 사람 검토로 검증해야 하며, 현재 문서는 구현·검증 완료 증거가 아니다.
