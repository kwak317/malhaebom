## 1. 문제 정의

- 대상: **신입 백엔드 개발자 준비생**
- 핵심 문제: 공고 요구사항과 자신의 실제 답변 근거를 연결해, 문제 해결 경험을 더 구체적으로 설명하기 어렵다.
- 핵심 흐름: **공고 원문/요구사항 → 사용자 기준 선택 → 답변·음성 분석 → 근거 기반 코칭 → 재답변 → 동일 기준 비교**
- 기준 문서: [문제정의서](product/problem-definition.md), [PROJECT_OVERVIEW](PROJECT_OVERVIEW.md)

## 3. 현재 아키텍처

```text
로그인
→ 공고 원문 조회 / 요구사항 추출·검증
→ 사용자가 요구사항 1~2개 선택
→ 연습 세션 / WAV 업로드
→ STT · VAD · 전달력 분석
→ 답변 확정
→ Agent API
→ Skill + MCP 문맥
→ LLM
→ 서버 계약 검증 · 저장 · Langfuse
→ 2차 답변
→ 동일 기준 비교
```

- 서버가 인증·허용 ID·출력 계약·인용 원문 일치·저장을 결정하고, LLM은 의미 해석과 코칭 제안을 담당한다.
- 기준 문서: [ARCHITECTURE](ARCHITECTURE.md), [CURRENT_STATE](CURRENT_STATE.md)
