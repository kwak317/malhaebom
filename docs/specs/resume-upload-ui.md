# 이력서 제출 카드 UI 정리

## Why
긴 안내와 기본 파일 입력이 프로젝트 채팅 UI와 어울리지 않고 검토 상태의 가독성이 낮다.
## Goal
기존 보라색 카드·아이콘·버튼 톤을 맞춘다. 분석/확인 기능과 개인정보 제외 안내는 유지한다. 배포·API 변경은 제외한다.
## What
간결한 제목/설명, 개인정보 안내, 접을 수 있는 상세 파일 처리 안내, 파일명/용량/선택 동작이 있는 업로드 영역, 검토 중 상태를 제공한다. 검토 결과와 확인 완료 결과는 한 채팅 안의 6종 요약 카드로 표시한다. 각 범주 상위 3항목을 최대 2줄로 미리 보여주고, 전체 내용·수정·삭제·근거는 접기 안에서 확인한다. 데스크톱 2열/모바일 1열이며 분석 후 업로드 영역을 숨기고 다른 파일 제출로 재진입한다.
## How
ResumeSubmissionChat 및 전용 CSS만 변경한다. 숨긴 접근 가능한 file input과 연결 label, SVG 아이콘, 긴 파일명 줄임, 모바일 버튼 재배치, reduced-motion 대응을 적용한다.
## AC
- 파일 선택/교체, 검토, 오류 수정, 결과 확인 기능 유지.
- 개인정보 제외 및 모델 전송/원본 보관 안내 접근 가능.
- 검토 중 파일 선택/버튼 비활성, 상태 표시.
- 데스크톱/390px에서 가로 넘침 없음, 기존 흐름 테스트와 build 통과.
