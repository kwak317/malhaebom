# 한국어 음성 감정분류 고품질 데이터 선별

## Why

- **페르소나**: 비공개 한국어 감정 음성 데이터로 모델을 실험하는 ML 개발자
- **상황**: 원본 데이터의 긴 무음·낮은 음량·손상 파일·중복이 파인튜닝 결과를 불안정하게 만든다.
- **문제**: 파일 수만 늘리면 감정 라벨별 품질 차이와 잡음이 모델 accuracy를 낮출 수 있다.
- **측정 지표**: 품질 통과 수, 제외 사유, 감정별 균형 후보 수

## Goal

- 원본 WAV를 변경하지 않고 품질 점수와 제외 사유를 남긴다.
- 다섯 감정의 같은 수만 고른 균형 후보 manifest를 생성한다.
- **Out of Scope**: 모델 학습, checkpoint 생성, 원본 음성·manifest 공개

## What

1. 작업자가 데이터 이용 범위를 확인하고 승인 인수로 실행한다.
2. 스크립트는 길이, 16 kHz mono 형식, 음량, clipping, 발화 비율과 중복을 검사한다.
3. 통과 파일의 품질 점수를 계산한다.
4. 감정별 최고점 파일을 같은 수로 뽑아 별도 manifest에 기록한다.

## How

- 입력: `manifest.csv`, `audio/`
- 라벨: 기쁨·당황·분노·불안·슬픔
- 허용 길이: 1.5~12초
- 음량: -35~ -8 dBFS
- clipping: 0.5% 이하
- 활성 발화 frame 비율: 45% 이상
- 출력: 품질 통과·제외·균형 manifest와 JSON 요약

## AC (Given-When-Then)

- GIVEN 데이터 승인 인수가 없을 때, WHEN 실행하면, THEN 원본을 처리하지 않고 중단한다.
- GIVEN 출력 폴더가 이미 있을 때, WHEN 실행하면, THEN 기존 결과를 덮어쓰지 않는다.
- GIVEN 형식·음량·무음 기준을 벗어난 WAV가 있을 때, WHEN 검사하면, THEN 제외 사유가 기록된다.
- GIVEN 모든 감정의 통과 후보가 있을 때, WHEN 균형 manifest를 만들면, THEN 감정별 파일 수가 같다.
- GIVEN Git 변경을 검토할 때, WHEN 파일 목록을 확인하면, THEN WAV·CSV·ZIP·모델 가중치가 없다.
