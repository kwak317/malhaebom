# 비교 후 면접 대화 시작 불가 안내

## Why
과거 기록은 비교 내용이 있어도 API가 요구하는 확정 revision·코칭 run·버전 조건을 충족하지 않을 수 있다. 자동 start의 409를 재시도 오류로 보여주면 같은 실패를 반복한다.

## Goal
start의 409는 정상적인 대화 불가 안내 1개로 처리하고 비교 결과를 유지한다. API 준비 상태 필드 추가·과거 기록 변경은 제외한다.

## What
대화를 시작하지 못하면 확정 답변과 동일 기준 코칭이 필요하다고 안내한다. 재시도·새 대화·전송 입력을 표시하지 않는다. 연결 실패/5xx는 기존 재시도, 이미 진행 중인 대화의 404/409는 기존 새 대화 복구를 유지한다.

## How
`InterviewFollowUpChat`의 start 실패에서 `InterviewChatApiError.status === 409`를 별도 상태로 처리한다. 비교 컴포넌트는 수정하거나 제거하지 않는다.

## AC
- Given 레거시 비교 내용, When start 409, Then 비교 결과와 대화 불가 안내가 남고 오류 alert·재시도·입력 폼은 없다.
- Given 일시적 start 실패, When 재시도, Then 기존 start request_id를 재사용한다.
- Given 시작 성공 후 기록 변경 409, Then 기존 오류와 새 대화 시작 복구를 유지한다.
