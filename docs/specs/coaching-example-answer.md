# 코칭 기반 예시 답변 1개 제공

## Why

- 대상: 프로젝트 문제 해결 경험을 처음 정리하는 신입 백엔드 준비생.
- 문제: 판정과 다음 행동만으로는 코칭을 문장에 적용하는 방법을 이해하기 어렵지만, 완성 답안은 없는 경험을 대필할 위험이 있다.
- 지표: 정상 응답 제공률 100%, 응답당 1개, 500자 이하, 확정 답변에 없는 숫자 0건.

## Goal

- 확정 답변과 검증된 코칭만 사용한 2~3문장 `example_answer`를 결과 화면에 표시한다.
- 확인되지 않은 역할·기술·수치·성과를 채우지 않는다.
- 여러 답안, 합격 답안 표시, TTS와 legacy `improved_answer` 재활성화는 제외한다.

## What

1. 코칭 출력이 예시 1개를 함께 생성한다.
2. 정보가 없으면 `[실제로 확인한 방법]`처럼 사용자가 채울 위치만 표시한다.
3. 범위 밖·서비스 실패 응답에서는 예시를 표시하지 않는다.

## How

- 내부 출력은 1~500자 `example_answer`를 필수로 가진다.
- 외부 응답은 `ok`·`needs_more_info`에서 문자열, `unsupported`·`unavailable`에서 `null`이다.
- 서버는 확정 답변에 없던 숫자를 거절하고 프런트는 사실 확인 안내를 함께 표시한다.

## AC

- GIVEN 지원 범위 안의 확정 답변 WHEN 코칭 성공 THEN 예시 1개가 응답과 화면에 표시된다.
- GIVEN 필요한 사실이 답변에 없음 WHEN 예시 생성 THEN 추정하지 않고 중립적인 자리표시자를 쓴다.
- GIVEN 확정 답변에 없는 숫자가 추가됨 WHEN 서버 검증 THEN 계약 위반으로 거절한다.
- GIVEN 범위 밖 또는 서비스 실패 WHEN 종료 응답 THEN `example_answer`는 `null`이고 영역을 숨긴다.
