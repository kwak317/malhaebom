# 준비 대화 출력·서버 정책 계약

## Why
경력 확인 질문과 일반 답변, 저장 요청과 저장 완료를 구분해야 한다.
## Goal
모델의 답변/질문을 별도 필드로 검증하고 저장·진행 판단은 서버 문맥으로 제한한다. 실제 DB/API 연결은 후속 PR이다.
## What
초안 제안, 최신 초안 확인, 명시적 저장 동의, 취소, 범위 밖 질문, 재답변 요청을 검증한다.
## How
Pydantic 출력 schema, exact source quote 검증, draft ID/version, consent gate. JSON/schema 실패에만 상태 변경 없이 최대 1회 재시도한다.
## AC
잘못된 동의/초안/원문이면 실행 요청 거절. 전송 예외/의미 오류는 자동 재시도 없음. JSON 2회 실패이면 현재 상태 유지.
