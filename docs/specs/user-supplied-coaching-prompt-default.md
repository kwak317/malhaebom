# 제공 코칭 프롬프트의 기본 적용

## Why

사용자가 첨부한 영문 코칭 시스템 프롬프트로 프로젝트 기본값을 교체하도록 요청했다.

## Goal

첨부와 동일한 기존 `coaching-user-supplied-v4-verification.md`를 기본 시스템 프롬프트로 선택한다. Skill과 서버 출력 계약은 유지한다.

## What

코드 기본값, `.env.example`, 로컬 `.env`의 코칭 Prompt 버전을 일치시킨다. 과거 프롬프트와 실험 후보는 재현용으로 보존한다.

## How

기존 버전별 로더를 사용하며 `{{skill_text}}`에 현재 Skill을 결합한다. 외부 게시, 컨테이너 교체, 두 단계 모델 호출 추가는 포함하지 않는다. 로컬 설정에 Langfuse Prompt 이름은 지정되어 있지 않다.

## AC

1. Given 기본 설정 When 시스템 프롬프트 로딩 Then 제공 프롬프트와 현재 Skill이 결합된다.
2. Given 기존 버전 명시 When 로딩 Then 기존 템플릿과 과거 빌더 hash가 유지된다.
3. Given provider 요청 When 구성 Then 생성한 프롬프트가 system 메시지에 전달되며 기존 계약 검증 테스트가 통과한다.

## 검증 한계

기존 v4 두 단계 실험은 범주별 품질 승격 기준을 충족하지 못했다. 사용자 요청에 따라 기본 선택을 바꾸며, 단일 호출 품질 개선이나 실제 사용자 E2E를 주장하지 않는다.
