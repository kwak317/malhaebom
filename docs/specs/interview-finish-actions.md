# 면접 연습 종료 후 이동

## Why

면접 대화 종료 뒤 요약만 남아 새 연습과 메인 화면으로 이동할 수 없다.

## Goal

- 종료 안내 아래에 `다시 면접하기`, `홈으로 가기` 2개 버튼을 표시한다.
- 새 연습에는 이전 채팅·공고·질문·답변 세션을 재사용하지 않는다.
- Out of Scope: 로그아웃, 저장된 연습 기록 삭제, 서버 세션 삭제 API, 기존 연습 흐름 변경.

## What

- `연습 마치기` 요청이 성공해 `finished`가 되면 안내 아래에 이동 버튼을 표시한다.
- `다시 면접하기`는 `/practice`를 새로 열어 React의 현재 연습 상태를 초기화한다.
- `홈으로 가기`는 `/`의 메인 화면을 연다.
- 종료 요청 중이거나 실패했으면 이동 버튼을 표시하지 않고 기존 재시도를 유지한다.
- 좁은 화면에서도 두 버튼이 줄바꿈되어 접근 가능해야 한다.

## How

- `InterviewFollowUpChat`의 종료 분기에 일반 링크를 버튼 모양으로 표시한다.
- 새 페이지 탐색으로 현재 `practice_session_id`, 대화 ID, 선택값과 채팅 메모리를 해제한다. 인증 저장소와 서버의 연습 기록을 삭제하지 않는다.
- `/practice`는 `App`의 새로운 `PracticePage`, `/`는 `IntroCoachRoomDemo`를 렌더링하는 기존 진입점을 사용한다.
- 새 API·의존성·라우터를 추가하지 않는다.

## AC

- GIVEN 대화 진행 중 WHEN 렌더링 THEN 종료 후 이동 버튼이 없다.
- GIVEN 종료 성공 WHEN 요약 표시 THEN 안내 아래에 두 링크가 각각 `/practice`, `/`로 표시된다.
- GIVEN 종료 실패 WHEN 오류 표시 THEN 이동 버튼 없이 `다시 시도`가 유지된다.
- GIVEN 종료 화면 WHEN 다시 면접하기 선택 THEN 새 문서의 연습 초기 화면을 열고 이전 대화·선택값을 재사용하지 않는다.
- GIVEN 종료 화면 WHEN 홈으로 가기 선택 THEN 메인 화면으로 이동한다.
