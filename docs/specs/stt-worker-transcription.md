# STT Worker 전사 Spec

## Why

- **페르소나**: 혼자 신입 개발자 면접을 연습하는 한국어 취업준비생
- **상황**: 사용자가 5~60초 답변을 녹음한 뒤 전달 방식을 확인하려 한다.
- **문제**: 후속 CPM·침묵·반복 분석에 사용할 일관된 한국어 전사문과 단어 시간정보가 아직 없다.
- **측정 지표**: 고정 평가셋 CER·WER·RTF·실패율·GPU 메모리, 단어 타임스탬프 존재율, `음`·`어` 보존율

## Goal

- **해결 목표**: 팀 GPU Worker가 검증된 로컬 음성 파일을 `faster-whisper`로 전사하여 후속 분석에 필요한 표준 JSON을 만든다.
- **성공 기준**:
  - 지원 입력에서 전사문, 구간·단어 타임스탬프, 모델 정보, 처리시간과 RTF를 반환한다.
  - 독립 단어로 인식된 `음`·`어`의 횟수와 위치를 손실 없이 전달한다.
  - 모델 로딩은 프로세스당 한 번만 수행할 수 있는 지연 초기화 구조를 사용한다.
  - 모델 의존성이 없는 단위 테스트로 결과 변환과 오류 처리를 검증한다.
- **Out of Scope**:
  - VAD·CPM·긴 침묵·반복 표현·피드백 우선순위 계산
  - API·Supabase·브라우저 녹음 연결
  - LoRA 가중치, AI-Hub 음성·전사문·checkpoint의 저장소 반입
  - 이 PR만으로 최종 STT 모델을 선정하거나 성능 개선을 주장하는 것

## What

### Happy Path

1. Worker가 검증 완료된 WAV·WebM·MP3 경로와 비민감 `source_id`를 받는다.
2. 설정된 `large-v3-turbo` 모델을 지연 로드한다.
3. 한국어 고정, 단어 타임스탬프 활성화, VAD 비활성화 조건으로 전사한다.
4. 표준 결과 스키마에 전사문·구간·단어·추임새 위치·처리시간·RTF를 반환한다.
5. CLI 사용 시 결과를 지정한 JSON 파일에 UTF-8로 저장한다.

### Edge Cases

| # | 상황 | 처리 방식 |
|---|---|---|
| EC-01 | 입력 파일이 없음 | 모델을 로드하지 않고 `FileNotFoundError` |
| EC-02 | 지원하지 않는 확장자 | 모델을 로드하지 않고 `ValueError` |
| EC-03 | 음성 길이가 0초 | RTF는 `null`, 빈 결과를 그대로 반환 |
| EC-04 | 단어 타임스탬프 없음 | 빈 단어 배열과 0회 추임새 반환 |
| EC-05 | `그 회사`, `저는`처럼 정상 어휘 | 독립 토큰 `음`, `어`만 집계하여 오검출 방지 |
| EC-06 | 모델 로딩·전사 실패 | 예외를 숨기지 않고 호출자에게 전달하며 전사문을 로그로 남기지 않음 |

## How

### 환경 설정

| 변수 | 기본값 | 설명 |
|---|---|---|
| `STT_MODEL_NAME` | `large-v3-turbo` | faster-whisper 모델명 또는 비공개 로컬 CTranslate2 경로 |
| `STT_DEVICE` | `cpu` | `cpu` 또는 `cuda` |
| `STT_COMPUTE_TYPE` | `int8` | CPU `int8`, GPU `float16` 권장 |
| `STT_BEAM_SIZE` | `1` | 모델 비교 시 동일하게 고정 |

### 결과 계약

```json
{
  "source_id": "attempt-uuid",
  "model": "large-v3-turbo",
  "language": "ko",
  "text": "전사문",
  "audio_duration_sec": 12.3,
  "processing_time_sec": 2.1,
  "rtf": 0.1707,
  "fillers": {
    "counts": {"음": 1, "어": 2},
    "total_count": 3,
    "occurrences": {"음": [], "어": []}
  },
  "segments": [],
  "words": []
}
```

- 로컬 절대경로는 결과에 포함하지 않는다.
- 사용자 전사문은 운영 로그에 출력하지 않는다.
- PR에는 모델 가중치·평가 음성·AI-Hub CSV를 포함하지 않는다.

## AC (Given-When-Then)

### AC-01 · 전사 결과 변환

- GIVEN: 구간·단어 타임스탬프가 포함된 faster-whisper 결과가 있다.
- WHEN: STT 서비스가 결과를 변환한다.
- THEN: 전사문, 구간, 단어, 처리시간, RTF가 표준 스키마와 일치한다.

### AC-02 · 추임새 집계

- GIVEN: 단어 결과에 `음`, `어`, `저는`, `그 회사`가 있다.
- WHEN: 추임새를 집계한다.
- THEN: 독립 토큰 `음`, `어`만 횟수와 위치에 포함한다.

### AC-03 · 입력 선검증

- GIVEN: 파일이 없거나 지원하지 않는 확장자다.
- WHEN: 전사를 요청한다.
- THEN: 모델 로딩 전에 명시적 예외를 반환한다.

### AC-04 · 민감 경로 제외

- GIVEN: 로컬 절대경로의 음성 파일을 전사한다.
- WHEN: 결과 JSON을 직렬화한다.
- THEN: 결과에는 전달받은 `source_id`만 있고 로컬 절대경로는 없다.

### AC-05 · 실행 검증

- GIVEN: 모델을 대체한 fake backend가 있다.
- WHEN: 단위 테스트를 실행한다.
- THEN: 외부 모델 다운로드 없이 AC-01~04가 모두 통과한다.
