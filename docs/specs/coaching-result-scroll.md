# 코칭 완료 후 결과 상단 이동

## Why

1·2차 답변 비교가 완성되면 일반 면접 메시지와 같은 하단 스크롤을 사용해 결과 제목과 답변 카드가 화면 위로 넘어간다.

## Goal

- 1차 코칭과 답변 비교가 완성되면 가장 최근 결과의 시작점이 채팅 상단에 보인다.
- 바로 뒤에 추가되는 면접 메시지가 결과를 읽는 위치를 덮어쓰지 않는다.
- Out of Scope: 코칭 내용, API, 저장 방식, 화면 구성 변경.

## What

- 완료 결과는 채팅 상단에서 24px 여백을 두고 표시한다.
- 이전 코칭 결과가 있어도 새로 완성된 결과로 이동한다.
- 일반 메시지는 사용자가 하단을 보고 있을 때만 자동으로 하단에 따라간다. 사용자가 위로 스크롤해 읽는 위치를 유지한다.
- README 분석 결과의 기존 상단 이동을 유지한다.

## How

- `useCoachThreadAutoScroll`에서 `.coach-coaching-result-message`와 `.coach-inline-comparison`을 같은 결과 대상으로 감지한다.
- 로딩 말풍선의 DOM을 재사용하는 경우를 위해 새 노드뿐 아니라 `class` 변경도 감지한다.
- 완료 시 하단 따라가기를 해제하고 마지막 결과의 위치를 사용한다.
- 하단 따라가기가 해제된 동안 일반 메시지가 예약된 결과 이동을 취소하지 않게 한다.

## AC

- GIVEN 긴 비교 결과 WHEN 로딩이 완료됨 THEN 제목과 답변 카드가 시작되는 결과 상단으로 이동한다.
- GIVEN 결과 상단 이동이 예약됨 WHEN 후속 면접 메시지가 추가됨 THEN 예약된 결과 이동과 읽는 위치가 유지된다.
- GIVEN 이전 코칭 결과가 있음 WHEN 새 코칭 결과가 추가됨 THEN 최신 결과로 이동한다.
- GIVEN 일반 대화 WHEN 사용자가 하단에 있음 THEN 새 메시지를 따라가고, 위로 이동하면 읽는 위치를 유지한다.
- GIVEN README 분석 WHEN 완료됨 THEN 기존 결과 상단 이동이 유지된다.
