# 코칭 채팅의 재답변 버튼

## Why
1차 코칭 직후 재녹음 카드로 진행을 유도하는 대신 사용자가 채팅 입력 영역에서 재답변 시점을 선택하도록 한다.

## Goal
보내기 옆 재답변하기 버튼 1개로 기존 녹음·WAV 업로드 흐름을 연다. 코칭 대화 모델/API 구현과 배포는 이번 변경 범위 밖이다.

## What
1차 코칭 완료 전에는 버튼을 사용할 수 없다. 코칭 완료 후 재답변하기를 누르면 같은 질문의 2차 녹음 패널과 WAV 파일 올리기를 표시한다. 녹음·업로드 진행 중 중복 시작을 막고 2차 완료 후 버튼을 숨긴다. WAV가 아닌 파일은 기존 오류 안내를 유지한다.

## How
PracticePage의 canStartSecondRecording·retryAnswer·기존 InlineChatRecorder 및 WAV 업로드 경로를 재사용한다. CoachingChatMessages는 호출자가 다음 행동 카드를 숨길 수 있도록 하며 독립 결과 화면과 2차 비교 카드는 유지한다. 서버 API·모델·저장 계약을 변경하지 않는다.

## AC
- Given 1차 코칭 완료 전, When 채팅 입력 영역을 확인, Then 재답변하기가 없거나 비활성이다.
- Given 1차 코칭 완료, When 화면 확인, Then 자동 재녹음 카드 대신 안내와 보내기 옆 재답변하기 버튼을 보여준다.
- Given 활성 버튼, When 클릭, Then 녹음 시작하기와 WAV 파일 올리기를 보여준다.
- Given 재답변 WAV, When 분석 시작, Then 같은 세션의 2차 답변으로 분석한다.
- Given 녹음 패널 또는 WAV 제출 대기, When 재답변하기 확인, Then 중복 시작은 비활성이다.
