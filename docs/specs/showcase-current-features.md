# 운영 기능 소개 및 실제 화면 미리보기

## Why
소개페이지에서 운영의 이력서·공고 추천·직접 질문·전사 보정·경험 추가·기록 기능이 충분히 드러나지 않고 목업/과거 데모가 현재 화면을 대신한다.

## Goal
빠진 기능 8개를 설명하고 실제 운영 화면 2개로 미리보기를 교체한다. 기존 두 도메인과 연습 시작·서비스 홈 동선을 유지한다. 제외: 앱 동작·백엔드·Prompt/Skill·Auth/DB 설정 변경.

## What
NCS/README, 이력서 PDF 분석, 공고 추천/검색/요구사항 선택, 직접 질문, 표준어 변환/원문·변경 확인, 자유채팅/동의 후 경험 반영, 이력서 초안/문장 다듬기/PDF, 기록 조회/삭제를 설명한다. 모든 자료는 선택적이며 원본 사실과 사용자 확인을 기준으로 한다.

## How
현재 main bc64a05 및 실제 malhaebom.xyz 화면을 기준으로 정적 HTML/CSS만 수정한다. 2026-10-10 운영 1280×900 캡처는 이름·연락처·실제 이력서·답변·계정 정보를 포함하지 않는다. 파일 경로/해시/캡처 상태를 manifest로 기록한다. 기획 예시 답변의 기존 고지는 유지한다. 사용자가 PR 생성·즉시 merge·기존 도메인 배포를 명시 승인했다.

## AC
- Given 소개 When 기능 탐색 Then 누락 8개 기능과 선택·동의 조건을 읽을 수 있다.
- Given 미리보기 When 이미지 확인 Then 현재 운영 NCS/이력서 제출 화면이며 목업/옛 데모를 현재 화면으로 제시하지 않는다.
- Given 375px/1280px When 렌더링 Then 가로 넘침 없이 이미지/글/링크를 확인한다.
- Given 기존 도메인 When 배포 후 접근 Then 양쪽 HTML·신규 캡처가 main 빌드와 일치하고 앱 JS/CSS는 이전 운영과 같다.
