# 연습기록의 답변 비교·꼬리질문 대화 펼치기

## Why

사용자는 연습기록에서 1·2차 답변 비교와 이후 꼬리질문 채팅을 클릭해 아래로 펼쳐 읽고 싶다. 현재 비교는 별도 상세 화면에 길게 펼쳐져 있고, 후속 채팅은 임시 메모리뿐이라 기록에 남지 않는다.

## Goal

- 목록에서 `결과 보기`로 진입한 비교 결과 화면에만 `1·2차 답변 비교`와 `꼬리질문 대화`를 기본 접힘으로 표시하고 각각 클릭·키보드로 아래에 펼친다.
- 완료한 후속 대화의 첫 질문부터 사용자 답변·후속 질문·종료 요약까지 순서대로 다시 읽을 수 있다.
- 본인 조회/삭제와 기존 24시간 만료를 유지한다. 과거 미저장 대화 복원, 새로운 대화 이어가기, 보관 연장, 모델/기준 변경, DB schema 변경은 제외한다.

## What

- 연습기록 목록 카드는 질문·일시·상태·결과 보기·삭제만 표시한다. `결과 보기`로 진입한 결과 화면과 상세 화면에 두 접힘 영역을 제공한다.
- 비교 영역에는 1차 답변·피드백·2차 답변·기준별 비교·전달력 변화와 주의 문구를 보존한다. 1차·2차 답변은 같은 연보라색 카드 배경을 사용한다.
- 대화 영역은 읽기 전용 말풍선이며 완료된 대화가 없으면 안내한다. 임의 과거 대화를 생성하지 않는다.
- 완료 대화 저장 실패 시 종료 요청을 재시도할 수 있으며 같은 모델 응답·대화 내용을 재사용해 중복을 막는다.

## How

- 기존 2차 `analysis_jobs.result` JSONB에 서버가 생성한 `interview_chat`만 추가해 저장한다. 기존 STT 결과·전달력·답변 revision·코칭·완료/만료 시각은 보존한다. 새 table/migration은 없다.
- 성공한 대화의 전체 메시지를 최근 12개 모델 문맥과 별도로 보존한다. 종료 시 사용자 JWT/RLS·세션 소유자·유효기간·확정 답변 fingerprint를 다시 확인한 뒤 저장한다.
- fingerprint는 두 답변별 revision ID·코칭 생성 시각·model·Prompt·Skill·criteria 버전으로 구성된 12개 값이며 저장과 조회에 동일하게 적용한다. 과거 4개 값만 가진 기록은 현재 기준으로 추정하지 않는다.
- 기록 API는 검증된 완료 대화만 노출한다. 만료되거나 현재 두 답변 fingerprint와 다른 대화는 표시하지 않으며 내부 fingerprint·만료 관리값은 응답에서 제외한다.
- 대화는 원래 답변의 근거나 새 LLM 문맥으로 소급 사용하지 않는다. 원문은 관측 로그/공개 자료에 보내지 않는다.
- 프런트는 공통 읽기 전용 접힘 컴포넌트를 결과·상세에서 재사용한다. 펼친 내용은 높이 제한 없는 문서 흐름으로 내려오며 모바일·키보드를 지원한다.

## AC

- Given 비교 기록 When 목록 열기 Then 두 접힘 영역과 답변/대화 내용이 없다. When 결과 보기로 진입 Then 두 영역이 기본 접힘이며 각각 펼침·접기가 가능하다.
- Given 1차만 완료한 기록 When 조회 Then 기존 결과 보기·삭제를 유지하며 가짜 비교/대화를 만들지 않는다.
- Given 긴 완료 대화 When 종료·서버 메모리 제거 후 기록 조회 Then 첫 질문과 모든 메시지·종료 요약이 순서대로 표시된다.
- Given 만료·소유자 불일치·삭제·답변 변경 When 종료 저장/조회 Then 허용하지 않으며 기존 결과를 변경하지 않는다.
- Given 종료 저장 실패 When 같은 요청 재시도 Then 추가 모델 호출·중복 메시지 없이 저장을 재시도한다.
- Given 과거 대화 미저장 When 펼치기 Then 저장된 대화가 없다는 안내를 표시한다.
