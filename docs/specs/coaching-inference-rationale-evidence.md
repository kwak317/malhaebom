# 원인 추론·행동 선택 이유의 근거 구분

## Why
실사용에서 비교 수행을 원인 추론으로, 수정 조치를 선택 이유로 확대하는 판정이 관찰됐다.

## Goal
두 기준의 충족 조건과 긍정·부정 예시를 Skill에 명시한다. 출력 계약·화면·배포는 범위 밖이다.

## What
- I는 실제 관찰 신호와 원인 후보를 연결하는 판단을 확인한다.
- D는 개인 행동과 독립적으로 해당 방법을 선택한 이유를 확인한다.
- 이유가 없으면 D는 not_observed, 원인 후보와 관찰의 연결이 부족하면 I는 partial이다.

## How
기존 SKILL.md에 경계 예시를 추가하고 problem-solving.md의 I/D 설명을 보완한다. ID·상태값·기존 카탈로그는 유지한다. 가상 예시는 실제 평가 데이터나 사용자 사실로 재사용하지 않는다.

## AC
- Given 수정 조치만 있는 답변, When D를 판정, Then 선택 이유를 추정해 met으로 처리하지 않는다.
- Given 비교했다는 행위와 원인 후보만 있는 답변, When I를 판정, Then 관찰 차이와 원인 판단 연결이 없으면 partial이다.
- Given 관찰 신호와 원인 판단 또는 선택 이유가 연결된 답변, When 해당 기준을 판정, Then 정확한 인용으로 met을 뒷받침할 수 있다.
- Given 수정된 Skill, When 기존 로더·프롬프트 검사를 실행, Then 참조 문서가 포함되고 출력 계약 검사가 통과한다.

실제 LLM의 AC 충족은 별도 재평가가 필요하다. 정적 예시와 로더 테스트를 모델 품질 증거로 간주하지 않는다.
