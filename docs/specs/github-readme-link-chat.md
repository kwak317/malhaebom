# 역량 선택 후 GitHub README 링크 제출 채팅

## Why

- 신입 백엔드 개발자 준비생이 자기점검한 역량 뒤에 자신의 프로젝트 설명 자료를 이어서 제시할 수 있게 한다.
- 일반 채팅 입력은 공고 검색 의도 분석으로 연결되어 있어 README 주소를 보낼 전용 입력이 필요하다.

## Goal

- 로그인 사용자가 NCS 역량 선택을 완료하면 GitHub README 링크를 요청하는 코치 메시지 1개를 표시한다.
- 사용자가 유효한 GitHub 저장소 또는 `README.md` 주소를 제출하면 현재 채팅의 사용자 메시지 1개로 표시한다.
- 사용자가 제출하지 않기로 선택하면 README 단계를 완료 상태로 표시하고 일반 채팅을 계속 이용할 수 있게 한다.
- **Out of Scope**: GitHub 내용 가져오기·분석하기, 저장소 접근 권한 확인, DB 저장, 코칭 근거로 사용하기.

## What

1. `선택 완료`로 자기점검 메시지가 표시된 직후 코치가 GitHub README 링크를 요청한다.
2. 입력칸은 `https://github.com/{owner}/{repo}` 또는 `https://github.com/{owner}/{repo}/blob/{ref}/.../README.md` 형식을 받는다. `www.github.com`도 허용한다.
3. 잘못된 주소는 입력칸 근처에 오류를 표시하고 제출을 유지한다. 유효한 주소는 현재 채팅의 클릭 가능한 사용자 메시지로 표시한다.
4. `건너뛰기`를 누르면 링크 입력을 닫고 건너뛴 선택을 채팅에 표시한다. 입력칸에 잘못된 주소가 있어도 건너뛸 수 있다.

**예외**

- 역량을 선택하기 전, NCS 조회 실패 시, 재답변 모드에서는 README 요청 메시지를 표시하지 않는다.
- 제출 후 중복 제출을 막는다. 새로고침하면 현재 화면의 선택과 링크 제출 상태가 초기화된다.
- 건너뛴 뒤에는 이 화면에서 README 분석을 요청하지 않는다. 새로고침하면 건너뛴 상태도 초기화된다.

## How

- 기존 `PracticePage` 상태와 채팅 메시지 스타일을 사용한다. 새 API는 만들지 않는다.
- `URL`로 HTTPS 및 GitHub 호스트를 확인하고 경로를 저장소 루트 또는 `README.md` 파일 경로로 제한한다.
- 이 링크는 공고 검색 `interpretJobSearchMessage`에 보내지 않는다.
- 건너뛰기는 프런트엔드 상태만 바꾸며 GitHub README 분석 API와 공고 검색 API를 호출하지 않는다.

## AC (Given-When-Then)

- **AC-01** GIVEN 로그인 사용자가 NCS 역량을 선택 완료함, WHEN 사용자 자기점검 메시지가 나타남, THEN README 링크 요청 코치 메시지 1개와 입력칸이 나타난다.
- **AC-02** GIVEN 유효한 GitHub 저장소 또는 README 파일 주소를 입력함, WHEN 제출함, THEN 주소가 클릭 가능한 사용자 채팅 메시지로 나타나고 공고 검색 API는 호출되지 않는다.
- **AC-03** GIVEN GitHub 외부 주소 또는 GitHub 내 README가 아닌 파일 주소를 입력함, WHEN 제출함, THEN 오류가 나타나고 사용자 채팅 메시지는 추가되지 않는다.
- **AC-04** GIVEN 역량을 아직 선택하지 않음, WHEN 채팅이 표시됨, THEN README 요청 메시지는 나타나지 않는다.
- **AC-05** GIVEN 역량 선택을 완료했지만 README를 제출하지 않음, WHEN `건너뛰기`를 누름, THEN 입력칸이 닫히고 건너뛴 채팅 메시지가 나타나며 README 분석 API는 호출되지 않는다.
- **AC-06** GIVEN 잘못된 주소로 제출 오류가 보임, WHEN `건너뛰기`를 누름, THEN 오류가 사라지고 일반 채팅 입력을 계속 사용할 수 있다.
