## PR 리뷰 반영

- 관리형 Prompt의 유효한 Skill 슬롯 옆에 `{{SKILL_TEXT}}`, `{{skill_text }}` 같은 오타가 있으면 기존 정규식이 이를 치환하거나 거절하지 않고 남기는 문제를 수정했다.
- 템플릿의 모든 이중 중괄호 표기를 검출하고 허용된 변수인지 확인한다. 짝이 맞지 않는 표기도 거절한다. 삽입된 Skill 본문은 다시 변수로 해석하지 않는다.
- 지원하지 않는 표기, 미완성 표기, 관리형 Prompt의 로컬 fallback 회귀 테스트를 추가했다. 분리 경계 테스트 10개와 백엔드 전체 526개가 통과했다.
- 이 수정은 템플릿 검증과 테스트에 한정된다. Docker 재빌드와 실제 Langfuse 호출은 여전히 미실행이다.
