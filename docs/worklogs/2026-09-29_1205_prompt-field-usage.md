# Worklog — 코칭 출력 필드별 사용 지시 추가

- 일시: 2026-09-29 12:05
- 작업자/에이전트: Codex
- 관련 이슈/PR: 없음
- 관련 요구사항/결정: 사용자가 스크린샷의 6개 출력 필드를 언제 어떻게 사용할지 프롬프트에 넣도록 요청했다.

## 1. 목적

시스템 메시지에서 각 출력 필드의 작성 시점, 검토 근거, 작성 방법을 명확히 한다.

## 2. 작업 전 상태

독립 등록 초안과 구현 현황 문서의 시스템 메시지는 동일하며, 필드 이름·타입·허용 값·개수 제한을 포함한다. 사용 시점 설명은 별도 항목으로 정리되어 있지 않다.

## 3. 수행 내용

- 시스템 메시지에 `필드별 사용 시점과 작성 방법` 항목을 추가했다.
- 공고 관련성, 질문 적합성, 기준별 판정, 추가 정보 질문, 연습 행동, 답변 재구성 예시의 작성 근거를 명시했다.
- 모든 응답에 6개 필드를 포함하고, 추가 정보가 없으면 질문은 null로 반환하도록 안내했다.
- 두 문서의 시스템 메시지를 함께 갱신했다.

## 주요 판단과 이유

표만 늘리지 않고 모델에 전달할 시스템 메시지 내부에 넣었다. 기준별 판정의 needed에서 질문을 만들고, 허용된 ID에 연습 행동을 연결하며, 예시에는 현재 답변의 사실만 사용하도록 기존 제한을 구체화했다.
