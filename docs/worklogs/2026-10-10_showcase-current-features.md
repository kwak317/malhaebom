# 운영 기능 소개와 최신 미리보기

사용자가 누락 기능 반영, 실제 운영 미리보기 교체, PR 생성·즉시 merge·기존 도메인 배포를 승인했다. 이번 요청에 한해 팀원 approve 대기 대신 사용자 명시 승인을 적용한다.

소개 HTML에 8개 기능 설명을 추가하고 이용 단계·FAQ를 보강했다. 프로젝트 상세의 경험/반복 흐름 설명도 정합화했다. 기획 목업·과거 데모를 운영 사이트의 NCS 자기점검·선택적 이력서 PDF 제출 2개 캡처로 교체했다. 실사용자 자료·계정 정보를 포함하지 않는다. 이미지 manifest에 URL·날짜·단계·SHA256 기록.

검증: 정적 자산/링크/앵커 검사 PASS, TypeScript/Vite production build PASS. 실제 브라우저에서 JPEG 2개 자연 크기 1280 확인, 1280px/375px 가로 넘침 없음, 기능 카드 8개 확인. 기존 앱 production JS app-Cocgu8GO.js 및 CSS app-CbE6pybw.css 동일. 앱/백엔드 기능 변경이 없는 정적 콘텐츠 수정으로 기존 전체 기능 테스트는 반복하지 않았다. 신규 provider/녹음/Google OAuth E2E 재실행은 포함하지 않는다.

배포 후 양쪽 도메인 HTML/캡처 해시를 확인한다.
