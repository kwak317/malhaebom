# 인천 채용정보 채팅 검색 연결

- 일시: 2026-09-23 KST
- 작업자/에이전트: Codex

## 목표

공고 검색 채팅에서 기존 세 출처와 함께 인천 채용정보의 진행 중인 공고를 보여준다.

## 구현

- 서버에서 `INCHEON_RECRUITMENT_API_KEY`를 이용해 인천 공식 API를 조회한다.
- 최근 최대 100건을 제목·회사명으로 필터링하고 마감 공고·비공식 링크를 제외한다.
- 채팅 결과에 인천 섹션과 공식 원문 링크를 추가한다.
- 원문 요건이 첨부 문서에만 있을 수 있어 인천 공고의 AI 분석·코칭 저장은 연결하지 않는다.

## 검증

- 인천 백엔드 테스트 4개 통과: 인증, 페이지 검색, 마감·미시작·비공식 링크 제외, 키 비노출.
- 관련 백엔드 테스트 35개가 모두 `OK`를 출력했으나, 기존 비종료 백그라운드 스레드로 테스트 프로세스가 종료되지 않아 중단했다.
- 프런트엔드 전체 69개 테스트와 프로덕션 빌드 통과. 추가한 인천 실패 격리 테스트까지 포함한 관련 화면 테스트 15개 통과.
- 실제 인천 API에서 `채용` 검색 결과 4건을 확인. 키 값은 출력하지 않았다.
- 로컬 Docker API·프런트엔드 이미지를 재빌드·재시작해 두 컨테이너가 healthy임을 확인했다. `/practice`는 HTTP 200, 인천 검색 경로의 비로그인 응답은 HTTP 401이었다.
- 프런트엔드 빌드 결과에서 인천 API 키 환경 변수 이름이 포함되지 않음을 확인했다.
- 백엔드 전체 244개 중 6개는 코칭 런타임/컨텍스트 테스트에서 실패했다. 인천 검색 코드와 직접 연결된 실패는 확인되지 않았다.
- 로그인한 브라우저 세션에서 실제 채팅 → 인천 카드 표시까지는 확인하지 못했다.
