## 1. 목적

실제 실행 API의 목록·개별 기록 조회 성공 로그를 찾고 합성 예시와 구분한다.

## 2. 작업 전 상태

구현 현황 문서의 조회 JSON은 현재 서비스 코드에 합성 기록을 넣어 만든 예시다. 응답 본문은 실제 조회 결과라고 표현하지 않는다.

## 3. 수행 내용

- 현재 Compose API 컨테이너의 최근 6000줄 접근 로그를 읽었다.
- `GET /practice-records`와 개별 기록 조회에서 HTTP 200 로그를 확인했다.
- 원본 로그, 한국 시간으로 변환한 시각, 컨테이너 ID·이미지·Compose 경로를 별도 근거 파일에 저장했다.

## 주요 판단과 이유

단위 테스트 HTTP 200과 실제 컨테이너의 HTTP 200을 구분했다. 성공 로그는 응답 본문이나 저장된 기록 수를 증명하지 않으므로 합성 JSON을 실제 조회 응답으로 교체하지 않았다.
