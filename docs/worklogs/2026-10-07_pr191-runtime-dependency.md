# PR #191 준비 대화 의존성 검토

- 프론트 준비 대화 API 연결은 선행 #194 계약과 #195 서버가 main에 반영된 뒤 머지한다. 운영에서는 PREPARATION_CONVERSATION_ENABLED=true 구성으로 이미 사용 중이다.
- 세션 생성 후 준비 대화 bind 실패가 녹음/WAV 준비 전체를 실패시키던 부분은 오류를 채팅에 표시하고 녹음 세션은 계속 사용하도록 수정했다.
- 준비 대화 요청 자체의 실패는 기존 오류 표시를 유지한다. 저장 성공으로 표시하지 않는다.
- 검증: 준비 대화 연결 실패 회귀 테스트 및 기존 대화 표시/연결 테스트.
