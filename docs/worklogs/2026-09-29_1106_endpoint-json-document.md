- 관련 요구사항/결정: 사용자 첨부 문서를 기준으로 스크린샷처럼 요청·응답과 조회 이력을 JSON으로 표시한다.

## 1. 목적

말해봄 API의 실제 필드 이름을 사용해 요청·응답·조회 이력·오류 예시를 문서에서 확인할 수 있게 한다.

## 2. 작업 전 상태

첨부본은 코칭 응답을 일부만 보여주며 조회 이력 JSON은 없다. 기존 로컬 문서는 첨부본과 내용이 달라, 첨부본을 기준으로 별도 수정본을 만든다.

## 3. 수행 내용

- `POST /api/agent`에 기존 mock HTTP 기록의 요청 및 전체 응답을 추가했다.
- `GET /practice-records`에 현재 서비스 코드로 만든 합성 기록 예시를 추가했다.
- 인증 누락 HTTP 401 JSON을 추가하고, 기존 2~4절은 보존했다.

## 주요 판단과 이유

기존 mock 응답과 합성 조회 예시의 근거를 구분해 표시한다. 조회 예시는 실제 사용자 DB 저장이나 실제 LLM 호출의 증거가 아니다.
