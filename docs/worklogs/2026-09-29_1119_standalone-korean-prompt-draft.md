# Worklog — Skill 참조 없는 한국어 코칭 프롬프트 초안

- 일시: 2026-09-29 11:19
- 작업자/에이전트: Codex
- 관련 이슈/PR: 없음
- 관련 요구사항/결정: 사용자 첨부 프롬프트 문서의 구성에 맞춰 한국어로 작성하고 Skill을 불러오지 않는다.

## 1. 목적

Langfuse 등록 정보, 실행 구성, 시스템 메시지, 사용자 메시지 템플릿, 출력 계약, JSON 예시를 갖춘 독립 프롬프트 검토 원본을 만든다.

## 2. 작업 전 상태

사용자는 시스템 프롬프트와 Skill의 분리를 요구했으며, 별도 프로젝트 프롬프트 문서를 형식 참고용으로 제공했다.

## 3. 수행 내용

- 프로젝트 상위 폴더에 한국어 등록 초안을 새로 작성했다.
- 시스템·사용자 메시지에는 Skill 참조·삽입 변수·로딩 지시를 넣지 않았다.
- 서버 문맥과 기준 ID·설명을 받는 입력 변수 2개 및 기존 6개 코칭 출력 필드를 명시했다.
- 단일 활성 기준을 가진 합성 JSON 예시를 추가했다.

## 주요 판단과 이유

프롬프트 자체와 서버 책임을 구분한다. 입력 변수 구성은 독립 프롬프트용 제안이며, 현재 런타임의 Skill 로딩 제거가 완료됐다고 표현하지 않는다. Langfuse에 실제 등록하지 않았다.

- 두 메시지의 Skill 파일·로더·참조·삽입 변수 부재 확인: 통과.
- Markdown 코드 블록 짝 및 JSON 예시 파싱: 통과.
- 출력 예시의 6개 최상위 필드 확인: 통과.
- 실행 API 이미지의 `CoachingLLMOutput.model_validate`로 예시 검증: 통과.

## 미확인 사항

- 실제 모델 품질, Langfuse 등록·조회, 독립 프롬프트 적용은 검증하지 않았다.

## 7. 다음 작업

## 추가 작업 — 문서 형식 정리

- 사용자 요청에 따라 내용은 유지하고 등록 정보, 시스템 메시지, 사용자 메시지, 출력 형식, 실행 구성 순서로 재배치했다.
- 제목에 번호를 붙이고 출력 필드 표와 응답 예시를 같은 항목 아래에 묶었다.
- 수정 전 문서는 `../output/docs/prompt-format-20260929-112137/before.md`에 보관했다.
- 검증: 시스템·사용자 메시지와 JSON 예시의 코드 블록이 수정 전과 완전히 일치한다. 제목과 빈 줄을 제외한 모든 본문 줄이 보존됐으며, JSON 파싱과 diff 검토도 통과했다.
- 런타임과 Langfuse 등록 상태는 변경하지 않았다.
