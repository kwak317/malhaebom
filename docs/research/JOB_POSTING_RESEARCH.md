# Job Posting Research

> 상태: 실제 공고 수집 전 템플릿.

## 목표

초기에는 신입 백엔드 실제 공고 3건을 확보·검토하고, 세션에서는 공고 1건의 관련 요구사항 1~2개만 사용한다.

## 원천 후보

- 고용24 채용정보 API
- 워크넷 직무데이터사전
- NCS 기준정보

공고 원문과 NCS/직무 정의의 역할을 구분한다. NCS는 기업의 실제 채점표가 아니다.

## 공고 스냅샷 최소 필드

- `posting_id`
- 회사/기관 식별명(허용 범위)
- 공고 제목
- source URL
- 수집 시각
- 최종 수정일
- 마감일
- `posting_snapshot_id`
- 원문/원문 위치
- 검토 상태

## 요구사항 최소 필드

- `requirement_id`
- `posting_snapshot_id`
- 원문 문구
- 원문 위치
- 유형: 업무 / 필수 / 우대
- 구조화된 짧은 설명
- 관련 질문 유형
- 검토자
- 검토일
- 검토 상태

## 직무/NCS 연결 필드

- 직무 분류/코드
- 능력단위명
- 정의
- 출처
- 버전/조회 시점
- 공고 요구사항과의 연결 이유
- 연결 검토 상태

연결이 불확실하면 비워둔다.
