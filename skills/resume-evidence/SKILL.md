# 이력서 근거 추출 규칙

## 추출 범위
- role: 명시된 지원 직무. 현재/이전 직무를 희망 직무로 추측하지 않는다.
- career: 경력/인턴의 근무 기간, 담당 업무, 정규직/인턴 구분. 프로젝트·교육 기간은 근무 경력으로 합산하지 않는다.
- technology: 기술명과 사용 맥락. 단순 기술 목록을 숙련도·개인 구현 경험으로 단정하지 않는다.
- project: 프로젝트 목적, 본인 역할, 구현 기능, 문제 해결 경험. 팀 경험을 개인의 역할로 바꾸지 않는다.
- education: 전공, 재학/졸업 여부, 졸업 예정 시점, 직무 교육. 학교 명성으로 추천 순위를 정하지 않는다.
- qualification: 자격명, 어학 등급/점수, 취득 시점.

## 근거와 제외 범위
- value는 짧은 정확한 원문 발췌, source_excerpt는 그 내용을 포함하는 해당 페이지의 연속 원문 문장이다.
- 원문을 요약·추론·재작성하지 않는다. 없는 항목은 반환하지 않는다.
- technology의 keyword는 원문에 명시된 기술 이름 한 개다. 다른 분류의 keyword는 null이다.
- 이름·연락처·상세 주소·사진·생년월일·성별·식별번호를 추출하거나 평가하지 않는다.
- 나이·성별·학교 명성·성격·합격 가능성·채용 적합성을 판정하지 않는다.
- 희망 지역·근무 방식·희망 고용 형태·입사 가능일을 추측하지 않는다.

## 가상 예시
- "Spring Boot 교육 수료"는 교육/기술 사용 맥락의 원문 근거다. "Spring Boot 실무 경력 3년"으로 바꾸지 않는다.
- "팀 프로젝트: 로그인 구현"만 있으면 해당 문장을 추출할 수 있지만 사용자의 개인 구현이라고 추가하지 않는다.
- 원문 "지원 직무: 백엔드 개발자"는 role로 추출할 수 있다.
